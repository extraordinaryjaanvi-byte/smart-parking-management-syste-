🚗 Smart Parking Management System
📌 Project Description

The Smart Parking Management System is a console-based application developed using the C programming language. It helps manage parking slots, vehicle entries and exits, parking fees, parking history, and total revenue efficiently.

The system provides an easy-to-use menu-driven interface for managing up to 10 parking slots.

✨ Features
View available and occupied parking slots.
Park a car or bike with automatic slot allocation.
Prevent duplicate vehicle entries.
Search for a parked vehicle.
Calculate parking fees based on parking duration.
Generate parking receipts.
Maintain parking history.
Generate revenue reports.

Car: ₹30 per hour
Bike: ₹15 per hour
